This addresses the reviewers' quantization question. With the same scoring code on both models, mAP at 0.5 falls from 0.849 to 0.781. Recall is preserved, but false positives rise by 78 percent at confidence 0.30, mostly on SARD tiles, and box tightness drops: mAP over IoU thresholds goes from 0.547 to 0.365. I have not investigated the cause yet. Calibration used validation images, which may flatter the compiled model, and was small, which may hurt it, so this is not a clean measure of INT8 loss; a recompile with 1,024 training tiles is planned.
